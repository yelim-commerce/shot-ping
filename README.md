# 샷핑! (SHOT-PING) — 새총 화살 × 쇼핑 슈팅 게임

앵그리버드처럼 **화면을 누른 채 뒤로 당겼다 놓으면** 화살이 포물선으로 날아갑니다.
40초 동안 **화장품·옷 타겟은 맞추고, 💣 폭탄은 피하는** 게임. 끝나면 이름·이메일로 경품 응모.

## 실행

```bash
python3 -m http.server 8000   # → http://localhost:8000
```

> 소리는 브라우저 정책상 첫 터치 이후 재생됩니다. 우하단 🔊 버튼으로 음소거.

## 규칙

| | 점수 |
|---|---|
| 🎯 타겟(화장품 4종 · 옷 4종) 명중 | **+100** |
| 🔥 연속 명중 (화살 기준) | 콤보 1단계마다 +20 (최대 +200) |
| 🏹 한 발로 여러 개 관통 | 두 번째부터 +50씩 |
| 💣 폭탄 명중 | **−200** (0점 아래로는 안 내려감) · 콤보 소멸 · 화살 소멸 |

- 빗나간 화살은 콤보를 끊습니다.
- 타겟은 링 모양 타이머가 다 돌면 사라집니다. 후반으로 갈수록 머무는 시간이 짧아지고
  좌우로 움직이는 타겟이 많아지며, 동시에 떠 있는 수가 5 → 8개로 늘어납니다.

### 타겟 : 폭탄 = 4 : 1

무작위 확률이 아니라 **타겟 4장 + 폭탄 1장을 섞은 덱**에서 한 장씩 뽑습니다.
그래서 5개가 나올 때마다 정확히 폭탄 1개이고, 폭탄이 3개 연속으로 나오는 일은 없습니다.
빈자리가 없어 배치에 실패하면 덱을 소모하지 않으므로 비율이 흐트러지지 않습니다.
`CONFIG.deck` 에서 바꿀 수 있습니다.

### 조작감

- 화면 어디를 눌러도 조준이 시작됩니다 (새총을 정확히 잡을 필요 없음). 당긴 방향의 반대로 발사.
- 당긴 거리 = 세기. 조준 중에는 **예상 궤적 점**이 앞쪽 일부만 보입니다.
- 발사 최대 속도는 화면 크기에서 역산해, 가장 먼 타겟 위치까지 항상 닿도록 맞춰집니다.
- 빠른 화살이 타겟을 건너뛰지 않도록 서브스텝으로 충돌 판정합니다.
- 가로·세로 화면 모두 지원 (세로에서는 타겟이 화면 위쪽에 배치).

coupon-pop 의 〈왕벌의 비행〉과 같은 계열(클래식 · 빠른 템포 · **미군 군악대 퍼블릭 도메인 연주**)입니다.

- 음원이 없거나 재생이 막히면 **WebAudio 합성 갤럽 리듬으로 자동 폴백**

## 📧 응모 웹훅 — coupon-pop 과 같은 Make.com 훅

```js
const WEBHOOK = {
  url: 'https://hook.eu1.make.com/iv6p47wuoc7rqnh1fb8884y0n5l6buuf',
  source: 'shot-ping-game',   // coupon-pop 은 'coupon-pop-game'
  ...
};
```

전송 방식도 coupon-pop 과 동일합니다.

- `application/x-www-form-urlencoded` (JSON 은 CORS preflight 로 Make 가 거부)
- fetch 실패 시 `sendBeacon` 재시도 → 그래도 실패하면 기기에 저장 후 3초 · 10초 · 45초마다 · 온라인 복귀 시 재전송 (건당 5회)
- 페이지를 닫거나 백그라운드로 갈 때 남은 응모를 `sendBeacon` 으로 밀어넣음
- 응모 화면은 전송 결과를 기다리지 않고 즉시 완료 처리

### 보내는 필드

| 필드 | 예시 | 비고 |
|---|---|---|
| `date` / `time` | `2026-09-13` / `14:02:11` | KST |
| `email` | `hong@shop.co.kr` | **필수** |
| `name` | `홍길동` | **필수** |
| `code` | `SHOT-8P6G` | 응모 코드 |
| `score` | `2340` | |
| `cleared` | `true` | 1500점 이상 |
| `agreedAt` | ISO 8601 | 동의 시각 |
| `source` | `shot-ping-game` | **게임 구분용** |
| `grade` | `A` | S/A/B/C |
| `hits` / `bombs` / `shots` | `21` / `2` / `30` | 타겟 명중 · 폭탄 명중 · 발사 수 |
| `accuracy` / `bestCombo` | `63` / `7` | 명중률(%) · 최고 콤보 |

기존 Make 시나리오에 `name` 이하 값은 매핑만 추가하면 됩니다. 개인정보 동의 체크는 필수입니다.
